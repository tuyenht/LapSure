# Role
Do not redesign product semantics. Review actual implementation/screenshots against:
- screen contract,
- component contracts,
- Design System,
- approved visual,
- Accessibility/DPI,
- UX copy.

Report P0/P1 visual/UX deviations with concrete locations and recommended fixes.
