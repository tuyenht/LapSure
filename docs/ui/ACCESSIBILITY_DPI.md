# Accessibility & DPI Contract

## Required targets
1366×768 and 1920×1080; Windows scaling 100%, 125%, 150%.

## Layout
No clipped primary CTA, overlapping cards or unreadably shrunk text. Reflow/scroll first; guidance rail may collapse.

## Keyboard
All primary controls reachable; visible focus; visual tab order; Enter/Space activate; Esc safely closes modal/full-screen test.

## Status
Never color alone; icon/shape + text; unavailable/gated reasons remain understandable.

## Text
Body 13–15 px equivalent, support 12–13, technical values monospace; no critical meaning only on hover.

## Dialogs
Initial focus on safest sensible control; destructive action not default; use native accessible labels where practical.
