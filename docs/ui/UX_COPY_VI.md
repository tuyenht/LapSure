# Vietnamese UX Copy Contract

Vietnamese-first, concise, task-oriented and non-alarmist. Explain why warnings exist. Never euphemize uncertainty as success.

## Canonical labels
PASS `ĐẠT`; GOOD `TỐT`; WARNING `CẦN LƯU Ý`; FAIL `KHÔNG ĐẠT`; CHANGED `CÓ THAY ĐỔI`; NOT TESTED `CHƯA KIỂM TRA`; UNSUPPORTED `KHÔNG HỖ TRỢ`; MANUAL REQUIRED `CẦN XÁC NHẬN`; PROVIDER UNAVAILABLE `KHÔNG CÓ NGUỒN DỮ LIỆU`; PERMISSION DENIED `THIẾU QUYỀN TRUY CẬP`; CANCELLED `ĐÃ HỦY`; INTERRUPTED `BỊ GIÁN ĐOẠN`; INCOMPLETE `CHƯA ĐỦ DỮ LIỆU`.

## Recommendation
BUY `CÓ THỂ MUA`; BUY WITH NOTES `CÓ THỂ MUA — CẦN LƯU Ý`; REJECT `KHÔNG NÊN MUA`; INCOMPLETE `CHƯA ĐỦ DỮ LIỆU ĐỂ KẾT LUẬN`.

## Preferred actions
`BẮT ĐẦU KIỂM ĐỊNH`, `BẮT ĐẦU KIỂM TRA TỰ ĐỘNG`, `TIẾP TỤC`, `KIỂM TRA LẠI`, `XEM BẰNG CHỨNG`, `XUẤT BÁO CÁO`, `KHÔI PHỤC PHIÊN`.

Warning pattern: `<what happened> — <what it means> — <recommended next action>`.

Avoid generic “health %” or reassuring statements while required evidence is incomplete.
