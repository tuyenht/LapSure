# Vietnamese UX Copy Contract

## Principles
- Vietnamese-first.
- Short, task-oriented, non-alarmist.
- Technical acronyms may remain English when standard.
- Explain why a warning exists.
- Never euphemize uncertainty as success.

## Canonical labels
- PASS → `ĐẠT`
- GOOD → `TỐT`
- WARNING → `CẦN LƯU Ý`
- FAIL → `KHÔNG ĐẠT`
- CHANGED → `CÓ THAY ĐỔI`
- NOT TESTED → `CHƯA KIỂM TRA`
- UNSUPPORTED → `KHÔNG HỖ TRỢ`
- MANUAL REQUIRED → `CẦN XÁC NHẬN`
- PROVIDER UNAVAILABLE → `KHÔNG CÓ NGUỒN DỮ LIỆU`
- PERMISSION DENIED → `THIẾU QUYỀN TRUY CẬP`
- CANCELLED → `ĐÃ HỦY`
- INTERRUPTED → `BỊ GIÁN ĐOẠN`
- INCOMPLETE → `CHƯA ĐỦ DỮ LIỆU`

## Final recommendation
- BUY → `CÓ THỂ MUA`
- BUY WITH NOTES → `CÓ THỂ MUA — CẦN LƯU Ý`
- REJECT → `KHÔNG NÊN MUA`
- INCOMPLETE → `CHƯA ĐỦ DỮ LIỆU ĐỂ KẾT LUẬN`

## Preferred actions
- `BẮT ĐẦU KIỂM ĐỊNH`
- `BẮT ĐẦU KIỂM TRA TỰ ĐỘNG`
- `TIẾP TỤC`
- `KIỂM TRA LẠI`
- `XEM BẰNG CHỨNG`
- `XUẤT BÁO CÁO`
- `KHÔI PHỤC PHIÊN`

## Warning copy pattern
`<what happened> — <what it means> — <recommended next action>.`

Example:
`SSD ghi nhận 23 lần mất nguồn không an toàn — đây chưa phải bằng chứng ổ đĩa hỏng. Xem SMART/NVMe và nhật ký để đánh giá thêm.`

Avoid:
- “Ổ cứng 98% khỏe” unless exact hardware endurance/capacity meaning exists.
- “Mọi thứ đều ổn” while required evidence is incomplete.
