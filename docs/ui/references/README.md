# LapSure Visual References

Images define visual hierarchy/layout/style only and never authorize fake diagnostic data.

Precedence: Coverage Contract → Product Spec → Architecture → UI Master Spec → State/Data contracts → Screen contract → Component contract → Known Deviations → Approved visual.

## Included in this downloadable bundle
- `CONTACT_SHEET.jpg` — global visual overview.
- `approved/` — full-dimension JPEGs using stable Screen-ID names.
- `originals/` — original source PNG mockups for archival/detailed inspection.
- `archive/` — superseded concepts.
- `LapSure_UI_Visual_Reference_Pack.zip` — compact repository-compatible visual pack.
- `MANIFEST.yaml` — machine-readable mapping.

## Repository behavior
The GitHub repository uses `LapSure_UI_Visual_Reference_Pack.zip` as the canonical complete visual source to keep source control lean; agents can extract the named member to a temporary location. This offline package additionally provides direct JPEG and original PNG files for convenience.

AI-generated text/numbers inside mockups may be illustrative or imperfect. Written product/screen/data/state contracts remain normative.
