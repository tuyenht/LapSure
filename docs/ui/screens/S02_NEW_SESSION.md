# S02 — Phiên kiểm định mới

`components: [C01,C02,C03,C05,C10,C11]`  
`visual: ../references/approved/S02_NEW_SESSION.jpg`

## User outcome
Create inspection context before evidence collection.

## Objects
Inspection purpose; Quick/Standard/Deep mode; session identity; optional seller/customer context; administrator/environment readiness; clear start action.

## Data
Session configuration and detected environment/capabilities. Do not prefill unsupported technical conclusions.

## Interaction
Starting creates/initializes the session and routes to required preparation/automatic audit. Destructive cancel/abandon requires explicit confirmation when evidence exists.

## Acceptance
Purpose/mode are understandable to a novice; readiness blockers are explicit; primary start CTA remains reachable at supported DPI.
