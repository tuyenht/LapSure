# S03 — Cam kết người bán

`components: [C01,C02,C03,C09,C10,C11]`  
`visual: ../references/approved/S03_SELLER_CLAIM.jpg`

## User outcome
Record seller-declared configuration/terms for later evidence-based comparison.

## Objects
Model, CPU, RAM, storage, GPU, display, asking price, warranty, listing/source, notes/evidence attachments where implemented.

## Data
`SellerClaim` and explicit user input. Empty fields remain unknown, never auto-filled from actual hardware as if seller-declared.

## Invariant
Seller mismatch is a comparison dimension, not automatic current-hardware failure.

## Acceptance
Clear save action, validation without inventing claims, later comparison traceable to original seller input.
