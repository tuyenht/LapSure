## User outcome
Guide operator verification of functions that cannot be certified by enumeration alone.

## Objects
Display; keyboard/touchpad; stereo; camera; microphone; Wi-Fi; Bluetooth; progress; skip consequence; next test.

## Data
`FunctionalTestSummary`, `FunctionalItemResult`, operator-confirmed evidence.

## Interaction
Each manual test explains stimulus/success criteria and records operator result. Interactive recording is gated until required automatic snapshot exists.

## Invariant
Presence never equals PASS. Skipped mandatory checks keep final decision incomplete.

## Acceptance
Manual evidence is labeled, non-happy states explicit, test navigation keyboard-safe and novice-readable.
