# S16 — Hồ sơ & Đối chiếu

`components: [C01,C02,C03,C04,C08,C09,C10,C12]`  
`visual: ../references/approved/S16_FACTORY_COMPARE.jpg`

## User outcome
Compare actual machine with factory/profile expectation and seller claim without conflating mismatch with health.

## Objects
Actual vs seller vs factory table; mismatch type; source/evidence; profile validation/confidence; impact notes.

## Data
`SellerClaim`, `FactoryProfile`, `ChassisProfile`, findings.

## Invariant
Factory/seller mismatch is an identity/commercial dimension; it is not automatically a current-health failure. Draft/generic profiles disclose confidence.

## Acceptance
Each difference is causal/traceable and does not create unsupported failure wording.
