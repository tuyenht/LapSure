# S17 — Thư viện bằng chứng

`components: [C01,C02,C03,C04,C08,C09,C12]`  
`visual: ../references/approved/S17_EVIDENCE_LIBRARY.jpg`

## User outcome
Organize evidence objects for review, drill-down and report traceability.

## Objects
Filter by domain/source/state; photos/screenshots; provider evidence; logs/raw records; operator evidence; report links.

## Data
Findings, evidence artifacts and session metadata actually persisted by the product.

## Invariant
The library does not fabricate missing artifacts or imply that absent evidence passed. Manual evidence is visibly attributed.

## Acceptance
Search/filter does not hide mandatory failures by default; evidence can be traced back to source/session.
