## User outcome
Provide searchable technical event/evidence drill-down without overwhelming novice screens.

## Objects
Session log; WHEA; disk/NVMe; NTFS; display; bugcheck; provider/runtime logs; filters; evidence detail.

## Data
`EventForensicSummary`, findings and actual session/live logs.

## Invariant
Historical events are not automatically current failure proof. Controlled pre/post deltas remain distinct.

## Acceptance
Source/time/context visible; filters preserve critical discoverability; empty/query-failed states explicit.
