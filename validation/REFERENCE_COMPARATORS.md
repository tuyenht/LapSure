# Independent reference comparators

Use these only for cross-checking during validation, not as mandatory runtime dependencies:
- BIOS/UEFI setup.
- Dell ePSA / built-in diagnostics where available.
- HWiNFO or equivalent inventory/sensor reference.
- smartctl for SMART/NVMe health.
- Windows Device Manager / USB4 settings.
- Windows battery report.

Disagreement must be logged; never silently force LapSure to match a comparator.
